Командная работа над проектом SkyproWallet

Командный проект SkyproWallet — это удобный и функциональный кошелек для учета расходов. В рамках этого проекта участники команды совместно разрабатывают полноценное приложение. Проект реализован в соответствии с макетом: https://www.figma.com/design/G6NqO7gpXDOS6ahqdBe0JB/Skypro.Кошелек? node-id=143-1395&t=TN66jSboWLLuNCzT-0 Распределение и учет задач осуществлялись на канбан-доске, которая помогала следить за ходом проекта и планировать дальнейшие шаги. https://zjkz14.kaiten.ru/space/647345/boards Для разработки интерфейса использовался React, Recharts — библиотека, основанная на D3.js, которая позволяет создавать графики с использованием HTML, SVG и CSS.

Участники команды
Екатерина Шевердяева — автор авторизации/регистрации, единого заголовка приложения
Ольга Петрова — автор работы с календарём и динамической диаграммы
Анна Милованова — автор таблицы и формы для добавления расходов
Функционал проекта Экран «Вход» Начальный экран.

Экран регистрации. Для ввода данных доступны поля «Имя», «Эл. почта» и «Пароль». При вводе данных текст становится черным. Кнопка «Войти» возвращает пользователя на экран входа.

Основной экран Кнопка «Мои расходы» перенаправляет на экран учета расходов. Кнопка «Анализ расходов» ведет на страницу аналитики. Кнопка «Выйти» перенаправляет на экран входа.

Функционал учета расходов Отображаются все внесенные расходы. Возможность фильтрации по категориям (например, еда, транспорт). Возможность сортировки по дате или сумме. Доступно редактирование и удаление расходов. Отображается общая сумма за выбранный период и затраты по категориям. Календарь для выбора периода Выбор периода по дням, неделям, месяцам и годам. Отображение всех данных за выбранный период. Доступна прокрутка календаря. Таблица расходов Отображение всех расходов с возможностью сортировки и фильтрации.
